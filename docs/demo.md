# Tachyon quick evaluation demo

This page is the shortest path for a recruiter or systems engineer to evaluate
Tachyon locally. It does not require a hosted service: the dashboard is a local
WebSocket demo at `http://localhost:8080` after you start it.

## 1. Headless smoke check

Use this when you only want to verify the C++ demo builds and emits deterministic
output. It does not require CMake.

```sh
bash scripts/smoke_demo.sh
```

What it does:

- builds `apps/main.cpp` and `apps/stream_demo.cpp` directly with the system
  C++17 compiler;
- runs the scripted CLI walkthrough and checks for `FINAL STATS`;
- runs a bounded five-event NDJSON stream and checks that order events are
  emitted.

Expected success shape:

```text
[smoke] building tachyon demo
[smoke] building tachyon_stream demo
[smoke] running scripted demo
[smoke] running bounded stream demo
[smoke] ok: demo ran and stream emitted 5 NDJSON events
```

## 2. Local dashboard demo

Prerequisites: Node/npm and a built `tachyon_stream` binary. The smoke script
places one at `build/smoke/tachyon_stream`; the CMake build places one under
`build/bin`.

```sh
# one-time dependency install if node_modules is absent
npm --prefix dashboard install

# syntax-check the dashboard bridge
npm --prefix dashboard run check

# start the local dashboard against the smoke-built streamer
TACHYON_STREAM=../build/smoke/tachyon_stream \
  PORT=8080 N_EVENTS=500 DEPTH=8 DELAY_MS=20 \
  npm --prefix dashboard start

# in another shell
curl http://localhost:8080/health
```

Open `http://localhost:8080` in a browser. The dashboard shows synthetic local
demo traffic generated by `tachyon_stream`: depth bars, BBO/spread stats, event
rate, and a trade tape. It is not connected to any public market or live hosted
demo.

## 3. Screenshot/GIF capture checklist

A screenshot is intentionally not committed here until captured from a current
local run. To add one for GitHub:

1. Run the dashboard command above.
2. Open `http://localhost:8080` and wait until depth/trade tape is populated.
3. Capture a 1200px-wide screenshot or short GIF.
4. Save it under `docs/assets/tachyon-dashboard.png` or
   `docs/assets/tachyon-dashboard.gif`.
5. Replace the README screenshot placeholder with a relative image link.

Avoid screenshots that imply a public hosted demo; label it as a local demo.

## 4. Benchmark caveat for reviewers

Published numbers are for the in-memory single-symbol matching loop only: no
network order entry, persistence, market-data fanout, or recovery path. Latency
numbers use the benchmark configuration stated next to the result and should be
compared only with the same compiler, CPU, build type, and timing method.
